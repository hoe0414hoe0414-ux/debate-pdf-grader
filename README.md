# 토론 PDF 채점 판독기 (데모)

학생들이 작성한 토론 수행평가 PDF를 올리면, 미리 입력한 채점 기준에 맞춰 채점하고 결과표로 보여 주는 웹 프로그램입니다.

**바로 열기:** https://hoe0414hoe0414-ux.github.io/debate-pdf-grader/

설치할 것이 없습니다. 인터넷이 되는 PC라면 어디서든 위 주소로 열면 됩니다. (크롬 또는 엣지 권장)

## 화면 구성

| 탭 | 하는 일 |
|---|---|
| 설정 | 학번 자릿수(4자리/5자리) 선택, **평가 영역 탭**마다 이름·채점 기준·파일 이름 키워드(차시 구분)·양면/단면 기본값·판독 참고 사항 |
| 업로드 파일 | 설정의 영역 탭이 그대로 생김. PDF 여러 개를 끌어다 놓으면 **파일 이름으로 영역을 자동 분류**(키워드 또는 ‘N차시’ → N번째 영역), 줄마다 영역 바꾸기, 이름순 정렬, X로 업로드 취소, 파일마다 자동/양면/단면 한 번 클릭 전환 |
| 채점 결과 | 결과는 항상 **학번 순**, 점수 칸은 좁게(가로 스크롤 없이 한 화면). 점수·학번·이름 칸을 눌러 직접 고칠 수 있음(고친 칸은 노란색, 비우면 원래 값, CSV에도 반영). 영역 이름을 누르면 학급 목록이 뜨고, 학급을 고르면 학생마다 **감점 키워드 + 학생 답안**이 함께 나옴. **학생 답안지 보기**: 왼쪽 답안지 원본, 오른쪽 채점 근거(50:50), ←/→로 학생 이동, 그 자리에서 점수 수정 |

### 평가 영역(탭)

- 설정의 ‘평가 영역별 채점 기준’에서 **+ 영역 추가**로 탭을 만들고 이름(예: 입론서, 반론서)을 적습니다. 영역마다 채점 기준이 따로 저장되고, 작성 중인 내용도 영역별로 임시 저장됩니다.
- 같은 이름의 탭이 업로드 파일 화면에 자동으로 생깁니다. 올린 PDF는 **파일 이름**으로 영역을 정합니다: 영역의 ‘파일 이름 키워드’(예: `1차시`, `입론`, 쉼표로 여러 개)나 영역 이름이 파일 이름에 있으면 그 영역, 키워드를 아무 데도 안 적었다면 `2차시` → 두 번째 영역처럼 차시 번호 순서, 못 찾으면 지금 고른 탭. 잘못 들어가면 목록 줄의 영역 선택 상자로 옮기면 새 기준으로 다시 읽습니다. 기준을 저장하기 전에 올린 파일은 기다렸다가 저장하는 순간 채점됩니다.
- 영역을 삭제하면 그 영역에 올린 파일도 함께 지워집니다(두 번 눌러야 삭제). 학번 자릿수는 모든 영역에 공통입니다.
- 예전 버전에서 저장한 기준은 ‘평가 1’ 영역으로 자동으로 옮겨집니다.

### 채점 기준 쓰는 법

AI에게 지시하듯 **자유롭게** 씁니다. 형식이 맞지 않아 저장이 막히는 일은 없습니다(비어 있을 때만 막힘).

```
## 평가 : 찬반 토론 입론서 작성

## 토론 주제
2번 : 국가는 국민의 생체 데이터를 빅데이터로 수집 및 활용해야 한다.

1. 사회 문제 탐색 : 30점 만점
학생이 주장하는 바가 명확하고 주제에 맞는가
2. 근거 제시 (40점)
3) 반론 대응 - 30점
```

- 글 전체가 그대로 AI 채점 지시문으로 쓰입니다.
- “1. 항목 : 30점”, “가) 항목 (20점)”, “- 항목 – 10점”처럼 점수가 붙은 줄은 결과표의 열(채점 항목)로 자동 인식합니다. 예전 형식 `항목 | 30 | 설명`도 됩니다.
- “상 : 30점”, “근거를 3개 이상 쓰면 10점” 같은 세부 규칙 줄은 항목이 아니라 설명으로 처리합니다.
- 배점을 하나도 못 찾으면 100점 만점 한 항목으로 채점하고 안내만 띄웁니다. 적힌 총점과 배점 합이 다르면 알려 줍니다.
- **감점식**도 됩니다. “1. 주장” 같은 번호 제목 아래 “- 주장이 누락된 경우(각 -4점)”처럼 감점 규칙을 적으면, 번호 제목이 결과표 항목이 되고 만점에서 감점을 뺍니다. 만점은 “만점 : 80점”처럼 적어 주세요(없으면 100점으로 보고 안내).
- “백지 … 48점”은 백지 점수, “총점이 48점 이하로 내려가는 경우 48점으로 표기”는 최저점으로 읽습니다. ‘유의사항·참고’ 제목 아래 번호 줄은 항목이 아니라 AI 지시로만 씁니다.
- AI에게는 적은 글 전문과 함께 위에서 읽어 낸 방식(배점/감점, 만점, 최저점, 백지 점수, 항목)을 정리한 지시문이 전달됩니다(`grader.js`의 `buildGradingPrompt`).
- 작성 중인 내용은 쓰는 동안 자동으로 임시 저장되어 새로고침하거나 창을 닫아도 남아 있습니다. ‘기준 저장’을 눌러야 채점에 쓰입니다.

## 양면 / 단면 스캔

드롭존은 하나입니다. 양면과 단면 파일을 섞어서 한 번에 올리면 파일마다 자동으로 판단합니다.

- 학번은 학년 1자리 + 반 + 번호 2자리로 읽어요 (5자리 20301 = 2학년 03반 01번, 4자리 2301 = 2학년 3반 01번). “2학년 3반 1번”처럼 풀어 쓴 것도 학번으로 바꿔요.
- **양면:** 앞+뒤 2쪽을 학생 1명으로 묶어 채점 (앞면에만 학번·이름이 있어도 됨)
- **단면:** 1쪽을 학생 1명으로 채점
- 반 전체를 한 파일로 스캔해도 학생별로 나눠서 결과표에 한 줄씩 나옵니다.
- 자동 판단 방법: 글자가 있는 PDF는 학번이 적힌 쪽마다 새 학생. 파일 이름에 학번이 있으면 학생 한 명의 파일. 스캔본은 앞쪽 24장까지 아주 작게 그려서 **답안지 양식이 몇 쪽마다 반복되는지**(1~6쪽 세트)를 찾습니다. 쪽 전체 모양과 학번·이름 칸이 있는 윗부분을 따로 비교하고, 스캔이 조금 밀린 것은 맞춰서 봅니다. 빈 뒷면도 잡습니다. (54쪽 스캔 파일 약 1초)
- 자동 판단이 틀리면 업로드 목록의 **자동 / 양면 / 단면** 버튼을 눌러 바꾸면 그 파일만 다시 채점합니다.
- 설정 탭에서 기본값(자동 판단 / 모두 양면 / 모두 단면)을 정할 수 있습니다.

## 바탕화면 바로가기 만들기

**방법 1 (가장 쉬움, 크롬/엣지):** 프로그램 주소를 연 뒤 주소창 오른쪽의 ‘앱 설치’ 아이콘(모니터 모양 ⊕)을 누르세요. 바탕화면과 시작 메뉴에 아이콘이 생기고, 창 하나짜리 프로그램처럼 열립니다.

**방법 2 (윈도우):** 이 저장소의 [`shortcut/install-desktop-shortcut.bat`](shortcut/install-desktop-shortcut.bat) 을 내려받아 더블클릭하면 바탕화면에 ‘토론 PDF 채점기’ 아이콘이 생깁니다. (‘Windows의 PC 보호’ 창이 뜨면 ‘추가 정보 → 실행’)

**방법 3:** [`shortcut/토론 PDF 채점기.url`](shortcut/) 파일을 내려받아 바탕화면에 두세요.

## 다른 컴퓨터에서 쓰기

1. 아무 브라우저에서 https://hoe0414hoe0414-ux.github.io/debate-pdf-grader/ 를 엽니다. 끝입니다.
2. 바로가기가 필요하면 위 ‘바탕화면 바로가기 만들기’를 따라 하세요.
3. 저장소 페이지(https://github.com/hoe0414hoe0414-ux/debate-pdf-grader)에서 초록색 `Code` → `Download ZIP` 으로 전체 파일을 받을 수도 있습니다.

> 채점 기준은 **브라우저마다 따로** 저장됩니다. 다른 PC로 옮길 때는 아래 ‘설정 파일’을 쓰세요.

## 설정 파일 (내보내기 / 불러오기)

- 설정 화면 오른쪽 위 **설정 내보내기**: 학번 자릿수와 모든 평가 영역(이름, 채점 기준, 작성 중인 내용, 파일 이름 키워드, 양면/단면, 판독 참고 사항)을 `.json` 파일 하나로 저장합니다.
- 다른 PC에서 **설정 불러오기**로 그 파일을 고르면, 무엇이 바뀌는지 먼저 보여 주고 ‘불러오기’를 눌러야 적용됩니다. 이름이 같은 영역에 올려 둔 PDF는 그대로 남습니다.
- 파일에 양식 버전이 적혀 있어, 프로그램이 바뀌어도 예전에 내보낸 파일을 그대로 불러올 수 있습니다(없는 항목은 기본값). 지금 양식은 **버전 2**(버전 1 파일은 파일 이름 키워드가 비어 있는 것으로 불러옴).
- 설정 파일에는 학생 PDF나 점수가 들어가지 않습니다.

## 개인정보

PDF는 **이 컴퓨터의 브라우저 안에서만** 읽고 채점합니다. 학생 파일이 인터넷으로 전송되거나 저장소에 올라가지 않습니다. 새로고침하면 업로드 목록은 비워집니다(기준과 설정은 유지).

## Claude 채점 (API 키 없이)

1. **업로드 파일** 화면의 ‘Claude 채점’ 칸에서 **채점 폴더 연결**(크롬·엣지) → PC의 보관 폴더를 고릅니다. 그 폴더에 `채점 도우미 켜기.bat`이 생깁니다.
2. `채점 도우미 켜기.bat`을 더블클릭해 켜 둡니다(PC에 Claude Code가 설치·로그인되어 있어야 함).
3. PDF를 올리고 **Claude 채점 시작** → 요청이 폴더에 저장되고, 도우미가 Claude로 채점해 `result.json`을 쓰면 프로그램이 자동으로 불러와 결과표·업로드 목록에 반영합니다.
- 도우미 없이: 프로젝트 채팅에서 Claude에게 “채점해줘”라고 하면 같은 폴더를 읽어 채점합니다. 폴더 연결이 안 되는 브라우저는 요청 zip을 내려받아 Claude에게 주고, 받은 `result.json`을 **결과 파일 불러오기**로 읽습니다.
- Claude가 따르는 절차와 결과 양식: [GRADING.md](GRADING.md), 예시: [examples/result.example.json](examples/result.example.json)
- 손글씨 스캔본은 PDF를 올려도 점수를 만들지 않습니다. 학생 나누기(몇 쪽이 한 명인지)까지만 하고, 학번·이름·점수 칸은 **판독 전 / 채점 전**으로 두었다가 Claude 결과를 불러오면 채워집니다. Claude는 학생마다 학번·이름, 항목별 **감점 키워드**(예: 주장 누락), 그 항목에 학생이 쓴 **답안**을 적어 줍니다(결과 양식 버전 2).

## 지금은 데모입니다

- 글자가 들어 있는 PDF(한글·워드에서 PDF로 저장한 파일): 실제로 본문을 읽고, 기준별 핵심어와 글 분량으로 점수를 냅니다.
- 손글씨 스캔본 PDF: 브라우저에서는 손글씨를 읽지 않습니다. 가짜 점수를 만들지 않고 ‘채점 전’으로 두며, 실제 판독·채점은 위 **Claude 채점**으로 합니다.
- 실제 AI 연결 지점: [`grader.js`](grader.js)의 `aiGrade()` 함수. API 키는 이 공개 저장소에 절대 넣지 말고, 별도 서버(예: Cloudflare Worker)에 보관해야 합니다.

## 속도를 위한 설계

- 빌드 도구·프레임워크 없이 순수 HTML/CSS/JS. 첫 화면에 받는 용량 약 50KB.
- PDF 엔진(pdf.js)은 첫 화면을 그린 뒤 한가할 때 미리 불러오고, 실제 해석은 별도 작업 스레드(Web Worker)에서 해서 화면이 멈추지 않습니다.
- 동시에 2개씩 채점하고, 상태가 바뀐 줄만 다시 그립니다. PDF 엔진 작업 스레드 하나를 계속 재사용합니다. (PDF 150개 테스트: 약 1.5초, 화면 끊김 없음)
- 두 번째 방문부터는 서비스 워커가 PDF 엔진을 저장해 두어 더 빨리 열립니다.
