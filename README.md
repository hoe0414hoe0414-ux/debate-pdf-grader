# 토론 PDF 채점 판독기 (데모)

학생들이 작성한 토론 수행평가 PDF를 올리면, 미리 입력한 채점 기준에 맞춰 채점하고 결과표로 보여 주는 웹 프로그램입니다.

**바로 열기:** https://hoe0414hoe0414-ux.github.io/debate-pdf-grader/

설치할 것이 없습니다. 인터넷이 되는 PC라면 어디서든 위 주소로 열면 됩니다. (크롬 또는 엣지 권장)

## 화면 구성

| 탭 | 하는 일 |
|---|---|
| 설정 | 학번 자릿수(4자리/5자리) 선택, 채점 기준 입력·검사·저장, 판독 참고 사항 |
| 업로드 파일 | PDF 여러 개를 끌어다 놓기, 이름순 정렬, X로 업로드 취소, 성공은 초록색·실패는 빨간색, 파일마다 양면/단면 한 번 클릭 전환 |
| 채점 결과 | 전체 결과표(학생 전체를 한 표로) + 파일별 상세 탭, 판독 불가는 빨간색 (채점 불가), 엑셀(CSV) 내려받기 |

### 채점 기준 쓰는 법

한 줄에 한 항목씩 `항목명 | 배점 | 설명` 으로 적습니다. `#`으로 시작하는 줄은 메모입니다.

```
주장의 명확성 | 30 | 자신의 입장(찬성/반대)이 분명하게 드러나는가
근거의 타당성 | 40 | 근거가 주장을 충분히 뒷받침하는가
반론 대응 | 30 | 예상되는 반론을 언급하고 반박하는가
```

입력하는 즉시 오류(배점이 숫자가 아님, 항목 이름 중복, `|` 빠짐 등)를 줄 번호와 함께 알려 주고, 오류가 있으면 저장 버튼이 잠깁니다. 저장된 기준만 채점에 쓰입니다.

## 양면 / 단면 스캔

드롭존은 하나입니다. 양면과 단면 파일을 섞어서 한 번에 올리면 파일마다 자동으로 판단합니다.

- **양면:** 앞+뒤 2쪽을 학생 1명으로 묶어 채점 (앞면에만 학번·이름이 있어도 됨)
- **단면:** 1쪽을 학생 1명으로 채점
- 반 전체를 한 파일로 스캔해도 학생별로 나눠서 결과표에 한 줄씩 나옵니다.
- 자동 판단 방법: 글자가 있는 PDF는 학번이 적힌 쪽마다 새 학생. 파일 이름에 학번이 있으면 학생 한 명의 파일. 스캔본은 앞쪽 8장까지만 아주 작게 그려서 ‘한 장 건너 양식이 반복되는지’, ‘뒷면이 비었는지’를 봅니다. (60쪽 스캔 파일 약 0.6초)
- 자동 판단이 틀리면 업로드 목록의 **자동 / 양면 / 단면** 버튼을 눌러 바꾸면 그 파일만 다시 채점합니다.
- 설정 탭에서 기본값(자동 판단 / 모두 양면 / 모두 단면)을 정할 수 있습니다.

## 바탕화면 바로가기 만들기

**방법 1 (가장 쉬움, 크롬/엣지):** 프로그램 주소를 연 뒤 주소창 오른쪽의 ‘앱 설치’ 아이콘(모니터 모양 ⊕)을 누르세요. 바탕화면과 시작 메뉴에 아이콘이 생기고, 창 하나짜리 프로그램처럼 열립니다.

**방법 2 (윈도우):** 이 저장소의 [`shortcut/install-desktop-shortcut.bat`](shortcut/install-desktop-shortcut.bat) 을 내려받아 더블클릭하면 바탕화면에 ‘토론 PDF 채점기’ 아이콘이 생깁니다. (‘Windows의 PC 보호’ 창이 뜨면 ‘추가 정보 → 실행’)

**방법 3:** [`shortcut/토론 PDF 채점기.url`](shortcut/) 파일을 내려받아 바탕화면에 두세요.

## 다른 컴퓨터에서 쓰기

## 개인정보

PDF는 **이 컴퓨터의 브라우저 안에서만** 읽고 채점합니다. 학생 파일이 인터넷으로 전송되거나 저장소에 올라가지 않습니다. 새로고침하면 업로드 목록은 비워집니다(기준과 설정은 유지).

## 지금은 데모입니다

- 글자가 들어 있는 PDF(한글·워드에서 PDF로 저장한 파일): 실제로 본문을 읽고, 기준별 핵심어와 글 분량으로 점수를 냅니다.
- 손글씨 스캔본 PDF: 손글씨 인식(OCR)·AI가 아직 연결되지 않아 **‘데모’ 표시가 붙은 임시 점수**를 보여 줍니다. 판독 불가 상황을 보여 주기 위해 일부 파일은 (채점 불가)로 나옵니다.
- 실제 AI 연결 지점: [`grader.js`](grader.js)의 `aiGrade()` 함수. API 키는 이 공개 저장소에 절대 넣지 말고, 별도 서버(예: Cloudflare Worker)에 보관해야 합니다.

## 속도를 위한 설계

- 빌드 도구·프레임워크 없이 순수 HTML/CSS/JS. 첫 화면에 받는 용량 약 50KB.
- PDF 엔진(pdf.js)은 첫 화면을 그린 뒤 한가할 때 미리 불러오고, 실제 해석은 별도 작업 스레드(Web Worker)에서 해서 화면이 멈추지 않습니다.
- 동시에 2개씩 채점하고, 상태가 바뀐 줄만 다시 그립니다. PDF 엔진 작업 스레드 하나를 계속 재사용합니다. (PDF 150개 테스트: 약 1.5초, 화면 끊김 없음)
- 두 번째 방문부터는 서비스 워커가 PDF 엔진을 저장해 두어 더 빨리 열립니다.

## 파일 구조

```

criteria.js           채점 기준 검사기
grader.js             PDF 판독·채점 (데모, AI 연결 지점)
sw.js                 오프라인/재방문 속도용 서비스 워커
vendor/pdfjs/         pdf.js 4.4.168 (Apache-2.0)
shortcut/             바탕화면 바로가기 파일
```
